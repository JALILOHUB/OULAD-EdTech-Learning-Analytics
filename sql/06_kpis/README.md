# KPI SQL

**Current status:** KPI definitions and KPI queries have not yet been finalized.

Planned areas include engagement, academic performance, retention, risk indicators, and data quality. Each KPI must have a written specification before implementation:

- business question and intended audience;
- grain and population included;
- numerator, denominator, and exclusions where applicable;
- time basis and grouping level;
- missing-value and repeated-record treatment;
- SQL implementation and reconciliation checks;
- interpretation limits, including the distinction between association and causation.

Do not publish a KPI in Power BI until its SQL definition and validation have been reviewed.
